    How this course works

    Every code block on this site is editable and runnable. The first time you click "▶ Run" on any page, a real Python interpreter — Pyodide, a full CPython build compiled to WebAssembly — downloads and starts up inside this browser tab.

    There is no server, no account, and no data ever leaves your device. pandas, numpy and (on request) plotly/scipy are loaded on demand the first time a snippet needs them, so the very first run of the day takes a few seconds — after that, everything is instant.

    The interactive charts in each module's Visual Lab tab are hand-built with Plotly.js so you can filter, zoom and hover — no coding required there, just explore.

    Progress is saved locally in your browser (via localStorage), so "Mark Complete" checkmarks persist between visits on the same device.
