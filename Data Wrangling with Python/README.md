## 🔎 Overview

**Practical Data Wrangling with Python** is a self-contained, interactive educational website — not a video, not a slide deck, and not a static tutorial. Every lesson lets you:

- 📖 read clear, focused explanations
- ✏️ edit real Python code inline
- ▶️ execute that code directly in the browser
- 📊 visualize results instantly with interactive charts
- 🧩 complete hands-on exercises
- 💡 reveal worked solutions when you're ready
- 🔬 learn by experimenting, not just reading

**No installation. No setup. No Jupyter, no terminal, no `pip install`.** Open the link, and you have a working Python + pandas + NumPy + Plotly environment ready to go.

## 🧪 Interactive Learning Experience

Each lesson in the course follows the same rhythm:

1. **Explanation** — a concise, plain-language walkthrough of the concept
2. **Editable code** — a live cell you can freely rewrite
3. **Run button** — executes your code instantly, in-browser
4. **Output** — printed results, tables, or errors, shown immediately
5. **Charts** — interactive Plotly visualizations where relevant
6. **Exercises** — practice problems tied directly to the lesson
7. **Solutions** — expandable, detailed sample approaches

You're actively encouraged to **change the code, break things on purpose, and rerun** — that's where the actual learning happens. This is a "hands stay on the keyboard" course, not a "read and scroll" one.

## 💡 Why This Course?

Reading about `groupby()` is not the same as watching your own aggregation silently produce the wrong number — and then figuring out why. Interactive, hands-on learning consistently beats passive reading because it forces:

- **Learning by doing** — you write and modify real code, not just read someone else's
- **Immediate feedback** — mistakes surface instantly, right where you made them
- **Experimentation** — "what happens if I change this?" is always one click away
- **Visual understanding** — charts make abstract transformations concrete

Data wrangling in particular is a *craft* skill — it's built through repetition on messy, imperfect data, not through memorizing syntax.

## ▶️ How to Use

1. **Open the course** using the link above.
2. **Read the lesson** explanation for the concept being introduced.
3. **Modify the code** in the editable cell — try your own approach.
4. **Click Run** to execute it in your browser.
5. **Observe the output** — tables, values, errors, or charts.
6. **Complete the exercises** at the end of each module.
7. **Reveal the solution** to compare your approach once you've tried.
