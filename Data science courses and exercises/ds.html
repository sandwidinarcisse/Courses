Setup Guide - Installing Your Data Science Toolkit

All Python code runs in the browser via Pyodide - no local installation needed. For local development, follow the steps below.

Step 1: Install Python 3.10+

python --version

Download from python.org/downloads

Step 2: Create a Virtual Environment

python -m venv venv
# Windows:  venv\Scripts\activate
# Mac/Linux: source venv/bin/activate

Step 3: Install Libraries

pip install pandas numpy scipy scikit-learn matplotlib seaborn nltk networkx pillow requests jupyter

Step 4: NLTK Data

import nltk
nltk.download('punkt'); nltk.download('stopwords'); nltk.download('vader_lexicon')

Step 5: Verify

import pandas, numpy, matplotlib; print('All good!')
