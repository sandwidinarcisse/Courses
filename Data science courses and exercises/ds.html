Setup Guide – Installing Your Data Science Toolkit

This guide walks you through setting up everything you need to run the code in this project. We will install Python and a set of libraries that data scientists use every day.

Step 1: Install Python

You need Python 3.10 or later.

Check if Python is already installed

Open a terminal (Command Prompt on Windows, Terminal on Mac/Linux) and type:

python --version

If you see Python 3.10.x or higher, you are good. If not, follow the instructions below.

Install Python

  • Windows: Download from python.org/downloads. Run the installer and check the box "Add Python to PATH".
  • Mac: Use Homebrew: brew install python@3.12
  • Linux: Use your package manager: sudo apt install python3.12 (Ubuntu/Debian)

    • Step 2: Create a Virtual Environment (Recommended)

    A virtual environment is an isolated space for your project's libraries, so they don't interfere with other Python projects on your machine. Think of it like a dedicated toolbox for this project.

    # Navigate to the project folder
cd "Data Scientist"

# Create the virtual environment
python -m venv venv

# Activate it:
# On Windows:
venv\Scripts\activate
# On Mac/Linux:
source venv/bin/activate

    You will see (venv) at the start of your terminal prompt when it is active.

    Step 3: Install Required Libraries

    With your virtual environment active, run:

    pip install pandas numpy scipy scikit-learn matplotlib seaborn nltk networkx pillow requests jupyter

    Here is what each library does:

    Library Purpose
    pandas Loading, cleaning, and manipulating tabular data (like Excel, but in Python)
    numpy Fast numerical computations; the foundation of most data science libraries
    scipy Scientific computing: statistics, optimization, signal processing
    scikit-learn Machine learning algorithms: classification, regression, clustering
    matplotlib The foundational plotting library for Python
    seaborn Beautiful statistical charts built on top of matplotlib
    nltk Natural Language Toolkit — text processing and analysis
    networkx Creating, analyzing, and visualizing graphs and networks
    pillow Image loading and processing
    requests Making HTTP requests to download data from the web
    jupyter Interactive notebooks for exploratory analysis

    Step 4: Download NLTK Data

    Some chapters use NLTK's built-in datasets. Run this once in Python:

    import nltk
nltk.download('punkt')
nltk.download('stopwords')
nltk.download('movie_reviews')
nltk.download('vader_lexicon')
nltk.download('averaged_perceptron_tagger')

    Or run the downloader interactively:

    import nltk
nltk.download()  # Opens a GUI downloader

    Step 5: Verify Your Installation

    Create a file called test_setup.py and run it:

    # test_setup.py
import sys
print(f"Python version: {sys.version}")

libraries = [
    "pandas", "numpy", "scipy", "sklearn",
    "matplotlib", "seaborn", "nltk", "networkx", "PIL", "requests"
]

for lib in libraries:
    try:
        __import__(lib)
        print(f"  [OK] {lib}")
    except ImportError:
        print(f"  [MISSING] {lib} -- run: pip install {lib}")

    Run it with:

    python test_setup.py

    All lines should show [OK].

    Optional: Install MongoDB (Chapter 12-13)

    Chapters 12 and 13 cover MongoDB. You can install it from mongodb.com/try/download/community.

    You will also need the Python driver:

    pip install pymongo
    Note: Chapters 12-13 include a "no-MongoDB" fallback that uses Python dictionaries to simulate the concepts. You can learn all the ideas without installing MongoDB.

    Troubleshooting

    "pip is not recognized"

    Try pip3 instead of pip, or python -m pip install ...

    "Permission denied" on Mac/Linux

    Add --user flag: pip install --user pandas

    ImportError after installing

    Make sure your virtual environment is activated. The (venv) prefix should be visible in your terminal.

    Slow installation

    Try a faster mirror: pip install pandas -i https://pypi.tuna.tsinghua.edu.cn/simple
